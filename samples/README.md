# 公開コードサンプル

主要プロダクト本体は非公開リポジトリで開発しています。公開側には、設計上の考え方を確認できるよう、依存関係を減らした小さなサンプルを置いています。

役割分担の詳細はPortfolioトップの説明にまとめています。

| サンプル | 実装環境 | 確認できる内容 |
|---|---|---|
| [AI実装結果の安全な適用](result_apply_guard.py) | Python | Git Head確認、変更範囲制限、結果不明時の再実行防止 |
| [取得情報の根拠確認](evidence_verification.js) | JavaScript | SHA-256、引用位置、改変検知、保存済みデータからの再検証 |
| [自動処理の再試行判断](automation_retry_policy.ts) | TypeScript | 失敗理由と処理状態に応じた再試行可否の判断 |

公開サンプルにはテストを付け、GitHub Actionsで実行しています。

ここで示したいのはプログラミング言語の習熟度ではなく、AIや自動化を使う際に、**状態、根拠、失敗、再試行、受入条件をどう設計するか**です。

製品固有の識別子や設定、周辺依存は公開用に削除・単純化しています。
