# 公開コードサンプル

主要プロダクト本体は非公開リポジトリで継続開発しています。

採用選考で設計・制御ロジックを確認できるよう、実プロダクトの考え方を依存関係の少ない形へ整理したサンプルを公開しています。

> **実装上の役割分担**  
> コード生成・直接実装には主にCodex / ClaudeなどのCoding Agentを活用しています。  
> 私は課題整理・要件・設計・受入条件・テスト観点・レビュー・受入判断を担当しています。

| サンプル | 実装環境 | 確認できる内容 |
|---|---|---|
| [AI実装結果の安全な適用](result_apply_guard.py) | Python | 状態遷移、対象Git Head確認、変更範囲制限、結果不明時の再実行防止 |
| [取得証拠の検証と再現](evidence_verification.js) | JavaScript | SHA-256、出典位置、改変検知、保存済みデータのみを使う再検証 |
| [自動処理の再試行ポリシー](automation_retry_policy.ts) | TypeScript | 失敗理由、再試行可否、安全性を優先した判定 |

## 公開している理由

示したいのはプログラミング言語の習熟度そのものではなく、AIや自動化を実運用へ近づける際に必要となる、

- 状態管理
- 根拠管理
- 評価
- 復旧
- 再現性
- 安全に失敗できる設計

の考え方です。

製品固有の識別子・設定・周辺依存は、公開用に削除または単純化しています。
