# 検証・改善事例 — 自動テスト通過後のレビューで重大な問題が見つかった

**テーマ:** 独立レビュー / 反証 / 再設計

## 事象

自動テストやCIがすべてPASSした後でも、独立レビューによって重大な問題が複数見つかったケースがありました。

## リスク

CI PASSを「設計そのものが正しい」根拠として扱うと、テストで確認していない観点や前提条件の誤りを見逃す可能性があります。

## 対応

CIを最終判断にせず、

1. 自動テスト
2. 独立レビュー
3. 問題原因の分析
4. 再設計
5. 回帰・異常系検証
6. 新しい条件で再レビュー

という流れへ戻しました。

## 他プロダクトへの横展開

「テストが通ったか」だけでなく、**どの失敗パターンを検証できているか**を確認する方針へ変更しました。

見つかった問題を、次回以降の確認ルール・回帰テストへ反映する考え方を複数プロダクトで共通化しています。

## 関連する能力

**評価 → 独立レビュー → 反証 → 回帰テスト → 学習**
