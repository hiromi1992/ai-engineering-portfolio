# AI開発基盤 / Review-Handoff Platform

**Coding Agentの実装結果を、Git・テスト・実際の変更内容から確認して受入可否を判断する開発基盤です。**

**現在の状態：非公開の開発リポジトリで主要機能を実装・検証済み。安全条件を確認できない自動実行は制限しています。**

## 何を作っているか

Coding Agentへ実装を任せた後、**AIの完了報告だけで判断せず、Git・テスト・実際の変更内容を確認して受入可否を決める**ための共通基盤です。

個人開発を続ける中で、AIが成功を返しても変更が反映されていない、古い状態を前提にレビューしてしまう、結果が分からないまま再実行してしまう、といった問題がありました。これらを個別対応ではなく、共通の開発ルールとして扱うために作っています。

## 主な仕組み

- 実行前に対象リポジトリ、対象タスク、変更可能な範囲を固定する
- AIの返答ではなく、Gitや対象ファイルの実際の状態を確認する
- 処理結果を確認できない場合は「結果不明」として扱い、確認前の再実行を止める
- 許可範囲外の変更や古いGit Headを拒否する
- テスト通過後も、重要な変更では独立レビューを行う
- 問題が見つかったら、実装だけでなく必要に応じて設計や要件まで戻す

## 検証状況

非公開の現行開発リポジトリでは **8 test files / 90 test cases** を確認しています。

主に、古いGit Head、範囲外変更、不正な状態遷移、結果不明時の再実行など、誤った完了判定につながるケースを検証しています。Ubuntu / Windows双方での確認も行っています。

## 自分の担当

- 問題設定
- 要件、状態、権限の設計
- Coding Agentへの実装指示
- テスト観点・回帰条件の設計
- Git・CI・実際の変更内容の確認
- 受入、修正、再設計の判断
