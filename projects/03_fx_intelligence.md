# FX Intelligence / TPI

**現在の状態：研究・評価基盤 v0.3.2 を実装済み。実売買・発注機能は持っていません。**

## 何を作っているか

USD/JPYの市場データを使い、仮説を作り、バックテストで検証する研究基盤です。

単に成績のよい条件を探すのではなく、**結果を見た後の条件変更で評価を都合よく歪めないこと**を重視しています。

## 主な設計

- 仮説を作る期間、検証期間、最後まで見ないデータを分ける
- 評価基準を事前に決める
- どの結果を既に見たかを記録する
- 結果確認後に条件を変えた場合は、元の実験の続きではなく別の実験として扱う
- 同じデータと条件で後から再検証できるようにする

## 検証状況

非公開の現行開発リポジトリでは **8 test files / 44 test cases** に加え、**46項目の受入条件**を管理しています。

データ分割、未使用データ、再現性、評価条件などが設計どおり守られているかを確認しています。

## 自分の担当

- 研究テーマ・仮説の定義
- 評価方法の設計
- データ分割と未使用データの扱い
- 受入・却下条件の設定
- Coding Agentへの実装指示
- テスト結果のレビュー
- 続行、修正、再設計の判断

コード生成・直接実装は主にCoding Agentへ委譲しています。
