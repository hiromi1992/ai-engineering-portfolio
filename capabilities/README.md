## 各プロダクトの位置づけ

- **AI開発基盤 / RHP** — AIへ実装を委譲し、検証・受入・復旧までを管理する共通基盤
- **Signal Harvester / ICP** — 判断に使う情報の根拠・出典・時点・履歴を整える情報基盤
- **FX Intelligence / TPI** — 仮説・予測・評価を、未使用データを残しながら検証する研究基盤
- **FormPilot** — 状態管理・復旧・安全な外部操作を業務自動化へ適用するプロダクト
- **Akashic Record** — 上記の知見を複数AIによる意思決定支援へ統合する長期構想
