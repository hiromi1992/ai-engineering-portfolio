## 共通の設計思想

各プロジェクトで共通している考え方は、[AIシステム設計で重視していること](../principles/ai_system_design.md) にまとめています。

主な考え方は、AIの自己申告を完了証拠にしないこと、元データとAI解釈を分けること、反証や不確実性を残すこと、結果不明の外部操作を再実行しないこと、評価データを結果に合わせて変えないことです。

| [FX Intelligence / TPI](../projects/03_fx_intelligence.md) | 8 test files / 44 test cases + 46項目の受入条件 |

件数そのものを成果とは考えていません。異常系や境界条件まで、どの程度検証しているかの参考として掲載しています。
