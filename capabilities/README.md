# 能力・プロダクト対応表

このページでは、**どの能力を、どのプロダクトで、どこまで実践・検証しているか**を整理しています。

## 表記

- **実践・検証済み** — 実装・テスト・レビュー等を通じて実際に扱っている
- **一部実践** — 限定された範囲で実装・検証している
- **設計段階** — 要件・設計上は扱っているが、十分な実装上の裏付けはまだない
- **—** — 現時点では対象外
